# Automation in Construction — Submission Guidelines

## Journal Info
- Publisher: Elsevier
- ISSN: 0926-5805
- Review: Double-anonymized peer review
- Impact Factor: ~10 (2025)

## Article Type
- Research Article (full-length original research)

## Format
- LaTeX class: elsarticle (elsarticle.cls)
- Bibliography style: elsarticle-num (numbered references)
- Single-column or double-column layout accepted
- No strict page limit, but typical research articles are 8000-12000 words
- Structured abstract required (max ~200 words)
- Keywords: 4-6 keywords

## Required Sections
1. Title, authors, affiliations (removed for double-blind review)
2. Abstract (structured, concise)
3. Keywords
4. Introduction
5. Related Work / Literature Review
6. Methodology
7. Experimental Setup / Data
8. Results and Discussion
9. Conclusions
10. Acknowledgements
11. References

## Double-Blind Review
- Remove author names and affiliations from manuscript
- Avoid self-identifying references where possible
- Use "the authors" instead of "we" if needed (though "we" is acceptable if not identifying)

## Figures and Tables
- High-resolution figures (300 dpi minimum)
- Figures should be interpretable in grayscale
- Tables in booktabs style preferred
- Captions should be self-contained

## References
- Numbered style [1], [2], etc.
- Use DOI where available
- Recent references preferred (last 5 years)

## Data and Code
- Data availability statement required
- Encourage open data and code sharing
