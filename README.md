# MorphoGraph-Infra

Semantic segmentation and graph extraction for concrete defect inspection.

## Installation

```bash
pip install -e ".[dev]"
```

## Repository Structure

```
scripts/          # Training, evaluation, and data preparation scripts
src/morphograph/  # Core library: models, losses, metrics, data
configs/          # YAML configurations
data/             # Data directory (not tracked)
```
